# ThreatOverlay — hold a key in battle to see where enemies can reach and strike (BepInEx 5)

Hold **Left Alt** in battle. Every hex an enemy can move to on its next turn is tinted red; every hex it could attack from there (its longest attack range from any reachable hex) is tinted orange. Release the key and the map returns to normal. Purely visual and local: nothing is changed or sent.

- Movement uses the game's own per-step cost (terrain, height steps, blocked hexes, movement-changing ground effects) with the enemy's next-turn movement budget; a Rooted enemy has none.
- Attack range is the enemy's weapon range or, by default, its longest harmful skill range.
- `Mode = HoveredEnemy` shows only the enemy under the mouse instead of all of them.

Config: `BepInEx\config\stolenrealm.threatoverlay.cfg` (F9 in game reloads it). Master switch: `ThreatOverlay = true/false` in `stolenrealm.mods.cfg`.

| Section | Key | Default | What it does |
|---|---|---|---|
| `1.Overlay` | `Enabled` | true | Master switch inside the mod. |
| `1.Overlay` | `HoldKey` | LeftAlt | Hold to show the overlay. |
| `1.Overlay` | `Mode` | AllEnemies | AllEnemies or HoveredEnemy. |
| `1.Overlay` | `ShowReach` | true | Tint hexes enemies can move to. |
| `1.Overlay` | `ShowStrike` | true | Tint hexes enemies can hit after moving. |
| `1.Overlay` | `IncludeSkillRanges` | true | Use the longest harmful skill range, not just the weapon. |
| `1.Overlay` | `ReachColor` | C83232 | Hex colour of reach hexes. |
| `1.Overlay` | `StrikeColor` | E08A3C | Hex colour of strike-only hexes. |
| `1.Overlay` | `RefreshSeconds` | 0.25 | Recompute interval while held. |
| `2.General` | `ReloadKey` | F9 | Re-read the config. |
| `2.General` | `VerboseLogging` | false | Log each recomputation (per enemy: budget, range, reach count). |

## How it works

`src/Patches/OverlayPatches.cs`. `Tick()` (from the plugin's Update while patched) checks battle state and the held key. On press and every `RefreshSeconds`: for each enemy in `Root.CharactersInBattleEnemyTeam` (or the hovered one), a Dijkstra over `HexCell.Neighbors` with `HexCellManager.HexCost(a, b, enemy, checkPlayers: true)` up to `max(TurnFreeMovementPoints, FreeMovementPoints)` (0 when `Rooted`) gives the reach set; `Within(reach, range)` expands by hex steps for the strike set, with `range = max(WeaponAttackRange, ActionInfo.GetSimpleRange(enemy, TargetInfo))` over harmful, simple-ranged, non-self actions in `Character.Actions`. Painting uses the game's own overlay object (`HexCell.CreateOverlay`, `overlay.SetActive`, `SetHighlightColor`) and registers the cell in `HexCellsWithActiveOverlays`. The game recolours a cell only inside `HexCell.UpdateHexCell`, so a postfix there re-applies the tint while held, and release calls `UpdateHexCell()` on every touched cell to restore the game's look.

Known limits: skill ranges are the simple radius only (line and blast shapes are not modelled); enemies that teleport or dash are shown by their walking range; the game may pass allies while pathing where the overlay treats occupied hexes as blocked.

## Rebuild

```
cd mods\ThreatOverlay
dotnet build -c Release
```

Follows the master-config pattern: `src/MasterConfig.cs` and `src/Plugin.cs` are generated by `tools/gen_master.py`.
