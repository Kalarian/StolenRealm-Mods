# ModMenu

The in-game switchboard. F9 opens a window listing every mod with a checkbox plus "Verbose logging (all mods)";
Apply writes `BepInEx\config\stolenrealm.mods.cfg` and makes every plugin reload on the spot; Cancel or Escape closes
without changes. A mod flagged `RestartRequired` in `src/ModTable.cs` shows "(restart required)" and Apply pops the
game's confirm dialog naming it (no mod needs that today). Plugins not present in `BepInEx/plugins` show
"(not installed)" with the box disabled.

## How it works

- `MenuWindow.cs` builds the window once at runtime from the game's own widgets: the checkbox is a clone of the options
  menu toggle (`OptionsManager.instance.screenShakeToggle`), Apply/Cancel are clones of the confirm dialog's buttons
  (`ConfirmWindow.Instance.ConfirmButton/CancelButton`), fonts come from the dialog's Title/Message labels, the panel
  borrows the dialog's frame sprite, and everything is parented next to the game's windows
  (`ReferenceLoader.Instance.StatManagerPlaceholder.parent`) so it scales with the UI. Plain fallbacks exist for each.
- A `UIWindow` component on the backdrop registers the window with `UIWindowManager` (`OpenWindow()`), so the game
  blocks its own input while it is open and Escape closes it (`OnCloseEvent` hides the panel). Outside a loaded game
  (`PauseMenu.instance == null`) it is a plain overlay closed by Escape from `Tick()`.
- Cross-plugin signalling lives in `MasterConfig` (identical copy in every plugin, generated by `tools/gen_master.py`):
  `MenuPresent` (AppDomain flag set from `Tick()`, cleared in `Reset()`), `RequestReload()` / `ReloadRequested(ref seen)`
  (an AppDomain int token) and `Write(states, verbose)`. Every generated `Plugin.Update` reloads when the token changes,
  and only reacts to its own `ReloadKey` when the menu is NOT present.
- Rows: whole row clickable (`RowClick`), hover shows the description as a game tooltip.

## Config `stolenrealm.modmenu.cfg`

`[1.Menu]` Enabled, OpenKey (F9), ShowDescriptions, CloseOnApply; `[2.General]` ReloadKey (same F9), VerboseLogging.

## Adding a mod

Add it to `PLUGINS`/`AllPlugins` in `tools/gen_master.py` and to `ModTable.cs` (title, one-line description,
RestartRequired), regenerate, rebuild all plugins (the MasterConfig copy changes in every one).
